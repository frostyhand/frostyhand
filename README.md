### `~` whoami

I am Tejaswi, founder and CEO of **[AxioRank](https://axiorank.com)**, the security gateway for AI agents.
AxioRank puts identity, policy, content inspection, audit, and cryptographic proof in front of every agent
action, so teams can ship autonomous agents without giving up control. Most of that work lives in private
repos. The open-source pieces below are free to use, and most of them run locally with no key.

<img src="https://raw.githubusercontent.com/frostyhand/frostyhand/main/assets/divider.svg" width="100%">

## Open source from AxioRank

<table>
<tr>
<td width="50%" valign="top">

### 🛡️ [gateway](https://github.com/AxioRank/gateway)
One local, OpenAI-compatible endpoint for every model provider. Guardrails on by default, with a signed,
offline-verifiable receipt on every response.

</td>
<td width="50%" valign="top">

### 🔎 [mcpaudit](https://github.com/AxioRank/mcpaudit)
Scan any MCP server for prompt injection, tool poisoning, and leaked secrets. One command, no key, with
SARIF output and a GitHub Action.

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 📜 [agent-security-gateway](https://github.com/AxioRank/agent-security-gateway)
The open AGS-1 spec: the five gates every agent action passes through (identity, policy, inspection,
audit, proof), plus a reference proof artifact you can verify offline.

</td>
<td width="50%" valign="top">

### 🧾 [agent-commerce-conformance](https://github.com/AxioRank/agent-commerce-conformance)
Open spec and reference verifier that proves an AI agent's purchase stayed inside the user's signed
mandate. Zero dependencies, verifiable offline.

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 📊 [enforcement-benchmark](https://github.com/AxioRank/enforcement-benchmark)
Reproducible evidence behind the AxioRank enforcement benchmark for indirect prompt injection. Harness,
corpora, raw verdicts, and model adjudication transcripts.

</td>
<td width="50%" valign="top">

### 🧩 Coding agent guards
Drop-in security for your coding agent. Block destructive commands, secret exfiltration, and
prompt-injected tool results locally, then mint a signed Coding Session Seal.
<br><br>
[Claude](https://github.com/AxioRank/claude-plugin) · [Codex](https://github.com/AxioRank/codex-plugin) · [Cursor](https://github.com/AxioRank/cursor-plugin) · [Grok](https://github.com/AxioRank/grok-plugin) · [OpenClaw](https://github.com/AxioRank/openclaw-plugin)

</td>
</tr>
</table>

```bash
npx @axiorank/mcpaudit <your-mcp-server-url>   # scan an MCP server for injection and secrets, no key
npx @axiorank/gateway                          # run the local, OpenAI-compatible security gateway
pip install axiorank                            # the Python SDK
```

Also shipping AxioRank into the tools teams already use: n8n, TYPO3, Backdrop, WordPress, Drupal, and Shopify.
